# HF Markets – Registration & Login

A registration and login landing page built with **Python (Django + Django REST
Framework)** and **SQLite**, following the provided Figma design.

> Work in progress – full documentation (design decisions, security notes, trade-offs)
> will be added as the project is completed.

## Requirements

- Python 3.12+

## Setup

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -e ".[dev]"
```

## Run the tests

```bash
pytest --cov
```
